# 验证与验收

## 回归入口

```powershell
& '<已验证python>' '<skill>\scripts\test_gis_editor.py'
& '<已验证python>' '<skill>\scripts\gis_editor.py' doctor
```

回归值为合成，不是研究结果。测试覆盖同一 Figure 的更新、数据数组不变、批量验证、revision 冲突、撤销/重做、样式恢复、输入变更门禁、字体缺失、三个矢量格式、连续色标同步、分类图例、栅格 NoData、CRS 缺失/冲突、无效几何、比例尺/真北、命令幂等、严格 JSON、导出尺寸和覆盖保护。

## GUI 实测

必须打开本地窗口确认不是只有静态图片。拖动标题/图例/图框，或用属性面板改字号；list 返回值确认变化，undo/redo 确认历史，关闭再恢复确认持久化。Agent send 发送 patch 后通过同一 Figure 的窗口和属性检验，不重跑工厂。导出后回读 PNG/PDF/SVG，核对尺寸、字体与真实画面。

不要通过绕过宿主 GUI 规则的 shell、私有 API 操作窗口。宿主限制无法完成某项真实 GUI 操作时说明该项未实测；不要用合成鼠标事件谎称真实桌面点击已经验证。

## 产物验收

- 成图含真实已确认指标及明确图例；示例含合成标注。
- 原始数据与指标未被改写；输入哈希一致。
- 字体覆盖用户文字，最终尺寸下无乱码/裁切。
- 图例、色标与实际颜色映射、分级、单位一致。
- 真实地图 CRS、范围、图层叠加与控制点检查完成。
- 布局审计仅声明实际覆盖范围，不等于全部地物遮挡检测。
- 文件存在、可读、尺寸正确；manifest 与成图哈希一致。
- 首图和微调使用同一个活跃 Figure；重启从配置重建，历史有效。
- 最新可用 Skill 目录交付，保留资源结构，不打 zip/.skill 包。

## 已知边界

对生产研究数据、第三方工厂、所有投影/图层数量、复杂跨日界线几何和各种复合 Artist 不声称全覆盖。测试通过只证明上述回归数据及当前环境。多主题、多面板和高分辨率栅格需对应任务实际验收。公开地图发布审核及科学结论仍需专业判断。
